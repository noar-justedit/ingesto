1Bienvenue

ingesto copie les rushes de vos cartes caméra sur autant de disques que nécessaire, puis relit chaque copie pour s'assurer qu'elle est identique à la carte. Il est gratuit, libre, et fonctionne sur macOS, Windows et Linux.

L'interface est en anglais

ingesto n'existe qu'en anglais. Ce manuel cite donc les boutons et les messages tels qu'ils apparaissent à l'écran, en gras : START INGEST, Settings… L'explication, elle, est en français.

Ce qu'il fait pour vous

  • Une carte, plusieurs disques, en un seul passage. La carte est lue une fois et écrite sur toutes les destinations en même temps. Les copies sont ensuite vérifiées en même temps, elles aussi.
  • Plusieurs cartes à la suite. Chargez un lot de cartes : elles passent l'une après l'autre, chacune vers toutes les destinations.
  • Des dossiers nommés pour vous. Chaque carte arrive dans un dossier construit à partir d'un modèle : compteur, nom de carte, opérateur, caméra, date…
  • Il reconnaît la caméra d'après l'arborescence de la carte, et remplit le champ caméra pour vous.
  • Il garde une trace de ce qu'il a fait : un rapport d'ingest sur chaque disque, des listes de checksums et des manifestes MHL si vous le souhaitez, et une notification sur votre téléphone si vous l'avez configurée.

Trois engagements

1 · Votre carte n'est jamais touchée

ingesto ne supprime, ne renomme et n'écrase jamais rien sur une carte qu'il copie. Pendant l'ingest d'une carte, toute écriture sur celle-ci est refusée. Seule exception : Card Tracking, une option désactivée par défaut qui n'écrit que son propre petit fichier journal (voir chapitre 14).

2 · « Verified » veut dire vérifié

Le mot verified n'apparaît que si chaque fichier a été relu sur chaque destination et comparé à la carte (modes SECURE et PRO). Une copie FAST affiche not verified, une copie SIZE CHECK affiche sizes checked, partout : à l'écran, dans le rapport, sur votre téléphone. Un ingest avec des erreurs n'est jamais présenté comme réussi.

3 · Il refuse de démarrer quand quelque chose ne va pas

Un disque débranché, deux cartes qui atterriraient dans le même dossier, une carte vide : ingesto s'arrête avant d'écrire quoi que ce soit, nomme le problème, et vous dit que rien n'a été copié.

2Installation et premier lancement

Télécharger

La dernière version se trouve sur la page des versions : github.com/noar-justedit/ingesto/releases/latest. Choisissez le fichier correspondant à votre système.

macOS

  1. Ouvrez le fichier .dmg.
  2. Glissez ingesto dans votre dossier Applications.
  3. Lancez-le par un double-clic normal. L'application est signée et notariée par Apple : aucun avertissement de sécurité.

Windows

  1. Lancez l'installeur.
  2. L'installeur n'est pas signé : au premier lancement, Windows SmartScreen affiche un avertissement. Cliquez sur More info (Informations complémentaires), puis Run anyway (Exécuter quand même). C'est normal.

Linux

Deux paquets sont proposés : le .AppImage fonctionne sur la plupart des distributions sans installation ; le .deb s'installe sur Debian et Ubuntu.

Le premier lancement

Pas d'assistant de configuration. La fenêtre s'ouvre directement, avec vos cartes et disques montés au centre. Le mode est SECURE, le réglage recommandé. Vous pouvez travailler tout de suite ; le chapitre 3 montre comment.

Mises à jour

Quand une nouvelle version sort, ingesto affiche New version available au lancement. Get it ouvre la page de téléchargement, Later ferme l'avis.

Votre ordinateur reste éveillé

Pendant un ingest, ingesto empêche l'ordinateur de se mettre en veille. L'écran peut s'éteindre ; la copie continue.

3Votre premier ingest en sept étapes

L'essentiel sur une page. Chaque étape est détaillée dans les chapitres suivants.

  1. Branchez votre lecteur de cartes et vos disques de destination. Ils apparaissent sous MOUNTED VOLUMES.
  2. Glissez la carte sur la zone SOURCES à gauche (ou clic droit → Set as SOURCE).
  3. Glissez un ou plusieurs disques sur la zone DESTINATIONS à droite (ou clic droit → Set as DESTINATION).
  4. Renseignez l'opérateur, la caméra, le profil d'image et les notes de la carte, si vous en avez besoin dans le nom du dossier ou dans le rapport.
  5. Vérifiez le nom du dossier affiché en vert sous chaque destination. Modifiez la FOLDER STRUCTURE si besoin.
  6. Choisissez le mode de copie. Gardez SECURE sauf raison particulière.
  7. Cliquez sur START INGEST. Attendez le bilan vert ALL FILES COPIED & VERIFIED avant de faire quoi que ce soit avec la carte.
Avant de formater une carte

Ne formatez une carte qu'après un ingest vérifié (SECURE ou PRO) sur au moins deux disques, avec un bilan vert. ingesto ne formatera jamais une carte à votre place.

5Charger les cartes

Trois façons de charger une carte

  • Glissez la carte depuis MOUNTED VOLUMES sur la zone SOURCES. Vous pouvez aussi la glisser depuis le Finder ou l'Explorateur.
  • Clic droit sur la carte → Set as SOURCE.
  • + Browse dans la zone Sources, pour choisir une carte ou un dossier.

Quand vous insérez une nouvelle carte, ingesto propose de l'utiliser : Use as source la charge, Ignore la laisse de côté.

Une carte chargée porte un badge rouge SRC1, dans la colonne Sources comme sur sa vignette. Le dossier qu'elle va créer s'affiche en vert sous son nom.

Les informations de la carte

Chaque carte a quatre champs :

  • OPERATOR : qui a tourné.
  • CAMERA : le modèle de caméra.
  • PICTURE PROFILE : SLOG3, CLOG, VLOG, HLG… choisi dans la liste ou tapé librement.
  • NOTES : texte libre, repris dans le rapport et la notification.

Ces valeurs peuvent servir dans le nom du dossier et apparaissent dans le rapport.

  • Reprises d'une carte à l'autre : opérateur, caméra et profil d'image sont conservés pour la carte suivante. Les notes décrivent une seule carte et sont effacées après chaque ingest.
  • (A) ou (M) : un petit (A) vert à côté de CAMERA signifie qu'ingesto a lu le modèle sur la carte. Un (M) gris signifie qu'il a été saisi à la main.
  • Le balai à côté de LOADED CARDS vide les quatre champs d'un clic.
  • Opérateur et caméra n'acceptent que lettres et chiffres, pour des noms de dossiers propres. Le profil d'image est écrit en majuscules et sans espaces : s-log 3 devient SLOG3.

Plusieurs cartes

Chargez autant de cartes que vous voulez. Chacune a son bloc, repliable avec la flèche. Elles passent l'une après l'autre, chacune vers toutes les destinations, chacune dans son propre dossier numéroté. Retirez une carte avec sa ×.

Carte protégée en écriture

Si le verrou de la carte est enclenché, ingesto vous prévient avant de démarrer. Vous pouvez continuer (rien n'est jamais écrit sur la carte de toute façon) ou retirer la carte.

6Choisir les destinations

Une destination est un disque, un RAID, un partage réseau ou un dossier qui recevra une copie complète de chaque carte.

Chargez-les comme les cartes : glisser sur la zone DESTINATIONS, clic droit → Set as DESTINATION, ou + Browse pour choisir un dossier précis. Chacune reçoit un badge vert DST1, DST2…

  • Sous chaque destination, ingesto liste les dossiers qu'il va créer, un par carte chargée. Vérifiez-les avant de lancer.
  • Vos destinations sont mémorisées d'une session à l'autre.
  • Les partages réseau (NAS) fonctionnent. En modes SECURE et PRO, ingesto relit vraiment la copie à travers le réseau, et non depuis la mémoire de l'ordinateur : la vérification est réelle. C'est plus lent ; c'est le prix d'un vrai contrôle.
  • Une destination ne peut pas être la carte elle-même, ni un dossier qui s'y trouve : ingesto refuse.
  • Avant de démarrer, ingesto vérifie que chaque disque a assez de place. Sinon, il vous le dit et vous laisse décider.
Combien de destinations ?

Deux est le minimum habituel en tournage : par exemple un disque de travail et un disque de sauvegarde. ingesto écrit sur tous en un seul passage : une troisième copie coûte peu de temps en plus.

7Nommer les dossiers

Chaque carte est copiée dans son propre dossier. Son nom est construit par la FOLDER STRUCTURE : une rangée d'éléments que vous assemblez.

Le menu Insert

Cliquez sur Insert pour ajouter un élément à la fin de la structure. Les éléments sont rangés par famille :

  • THE CARD : compteur, nom de carte, caméra, profil d'image, opérateur.
  • THE DATE : année, mois, jour, heure, minute.
  • TYPED BY YOU : Custom text… ajoute un texte fixe, comme DAY1 ou le nom d'un client.
  • SEPARATORS : tiret bas _ ou trait d'union -.

Glissez les éléments pour les réordonner. La × d'un élément le retire.

Double-cliquez sur la rangée pour taper toute la structure à la main.

Ce que devient chaque élément

ÉlémentDevientExemple
{counter}Le numéro de la carte (chapitre 8)004
{cardname}Le nom de la carteA001
{operator}Le champ opérateurALEX
{camera}Le champ caméraFX6
{pp}Le champ profil d'imageSLOG3
{YY} / {YYYY}Année, 2 ou 4 chiffres26 / 2026
{MM} {DD}Mois, jour10 01
{HH} {MIN}Heure, minute de l'ingest14 35

La structure par défaut donne par exemple : 004_A001_ALEX_FX6_261001_1435.

Un champ vide ne crée rien, pas même un séparateur orphelin. Vous n'obtiendrez jamais 004__FX6.

Sous-dossiers

Le bouton / commence un sous-dossier. Un seul ingest peut ainsi construire toute l'arborescence de votre projet, à l'identique sur chaque destination.

Exemple : DAY1 / {camera} / {counter}_{cardname}… donne DAY1/FX6/004_A001_ALEX_261001.

Les éléments de sous-dossier s'affichent en bleu, le dossier propre à la carte en vert. Un élément en italique est un texte que vous avez tapé.

Quelques règles, toutes contrôlées avant la moindre écriture :

  • Le {counter} doit se trouver dans le dossier propre à la carte, après le dernier /.
  • Quatre niveaux au maximum.
  • Un niveau de sous-dossier qui se retrouve vide (une carte sans caméra, par exemple) est simplement sauté. Le dossier propre à la carte, lui, ne peut jamais être vide : ingesto refuse plutôt.
  • Un / tapé dans un champ (opérateur, caméra…) ne crée jamais de dossier. Seule la structure décide.

Modèles

La zone TEMPLATES garde quatre structures, chacune avec un nom. Celle en cours d'utilisation porte une coche.

  • Cliquez sur un modèle rempli pour le charger.
  • Cliquez sur un modèle vide pour y enregistrer la structure actuelle ; vous pouvez lui donner un nom.
  • Clic droit sur un modèle pour le charger, l'écraser ou le supprimer.
  • Les icônes de l'en-tête enregistrent, exportent et importent les modèles, pour les partager avec un autre poste.

8Le compteur

Le compteur numérote vos cartes : 001, 002, 003… Il reste en bas de la colonne de gauche.

Auto (le cas normal)

ingesto regarde ce qui existe déjà sur vos destinations et prend le numéro libre suivant. Les cartes ont des numéros qui se suivent d'une session et d'un jour à l'autre. last: 003 sous le compteur indique ce qu'il a trouvé.

Manuel

Tapez un numéro ou utilisez − / + pour imposer une valeur. Elle reste bloquée jusqu'à ce que vous cliquiez sur Auto, qui revient à la numérotation automatique.

Nombre de chiffres

Le ⓘ à côté de COUNTER permet de choisir 2, 3 ou 4 chiffres (07, 007, 0007). C'est un minimum : après 99 vient 100.

Pourquoi c'est important

Le compteur est global à la destination, même avec des sous-dossiers par jour ou par caméra. Un trou dans la numérotation signifie donc qu'une carte manque.

Un numéro déjà utilisé

Si le numéro choisi existe déjà sur une destination, ingesto refuse de démarrer et propose de changer le compteur ou de vous montrer le dossier existant. On n'écrit jamais dans le dossier d'une carte existante.

9Choisir un mode de copie

Le mode décide du niveau de contrôle de chaque copie. Il se choisit en bas de la colonne centrale.

ModeCe qu'il contrôleQuand l'utiliser
FASTRien. Copie seule. Affiché not verified.Matériel jetable, ou copie supplémentaire que vous vérifierez ailleurs.
SIZE CHECKQue chaque fichier copié a la même taille que l'original. Détecte une copie interrompue ou un disque plein, pas un fichier corrompu. Affiché sizes checked.Quand le temps manque vraiment et que vous acceptez le risque.
SECUREChaque fichier est relu sur chaque destination et son empreinte (xxHash) comparée à celle de la carte. Détecte toute corruption, jusqu'au moindre bit.Recommandé pour tous les rushes. Le réglage par défaut.
PROTout ce que fait SECURE, plus des listes de checksums et des manifestes, le choix de l'algorithme, et la double lecture de la source en option.Quand une post-production, une archive ou un workflow demande des fichiers de checksums.

Le ⓘ à côté de COPY MODE explique chaque mode dans l'application.

Les options PRO

  • Algorithme : xxHash64, xxHash128 ou MD5. Prenez celui que demande votre post-production ou votre archive. MD5 est nettement plus lent.
  • Double source read : après la vérification des copies, ingesto relit la carte une seconde fois et contrôle qu'elle rend les mêmes données. Une carte qui répond différemment est en train de lâcher ; ses fichiers sont signalés. La vérification dure environ deux fois plus longtemps.
PRO n'est pas « plus sûr »

SECURE garantit déjà vos copies au bit près. PRO ajoute des fichiers destinés à d'autres outils. Si personne ne vous a demandé de listes de checksums, SECURE est le bon choix.

Les fichiers de checksums et les manifestes écrits en PRO se choisissent dans les réglages, section WRITE CHECKSUM (chapitre 14).

Pourquoi SECURE prend plus de temps

Vérifier, c'est relire chaque fichier sur chaque disque. ingesto contourne volontairement la mémoire cache de l'ordinateur pour que la lecture vienne vraiment du disque. Sur un disque lent ou un partage réseau, la vérification peut durer aussi longtemps que la copie.

10Lancer et suivre un ingest

Le bouton START INGEST

Son libellé indique ce qui manque : Load a card (chargez une carte), puis Choose a destination (choisissez une destination), puis START INGEST quand tout est prêt.

Des contrôles avant toute écriture

Quand vous cliquez sur Start, ingesto contrôle tout d'abord. Si quelque chose ne va pas, une fenêtre explique quoi, pourquoi, et que faire. La ligne Nothing has been written confirme que vos disques et votre carte sont intacts.

Cas typiques :

  • un disque ou une carte qui n'est plus branché ;
  • deux cartes qui atterriraient dans le même dossier (ici, deux cartes nommées A001 sans compteur dans la structure) ;
  • un numéro de compteur déjà utilisé sur une destination ;
  • pas assez de place libre ;
  • une carte sans rien à copier.

La file d'ingest

Pendant l'ingest, la colonne centrale affiche la file, et seulement elle.

  • L'anneau en haut à gauche suit toute la file, toutes cartes et toutes phases comprises, avec les cartes restantes, la taille totale et le temps restant.
  • Les tuiles en dessous donnent le fichier en cours, les fichiers et données restants, la vitesse et le temps estimé. Une tuile Errors apparaît en cas de problème.
  • Un bloc par carte, avec une ligne par destination, chacune avec son pourcentage et sa vitesse. Un disque à la traîne se voit d'un coup d'œil.
  • La couleur indique la phase : vert pendant la copie, bleu pendant la vérification, violet pendant la double lecture de la source, rouge en cas d'erreur.

Pause et annulation

PAUSE termine le fichier en cours puis attend ; Resume reprend. CANCEL arrête l'ingest. Tout le reste (cartes, destinations, structure, compteur, mode) est verrouillé pendant la copie : ce que vous modifiez après avoir cliqué sur Start ne peut pas toucher une copie déjà lancée.

Quitter pendant un ingest

Si vous essayez de quitter pendant une copie, ingesto demande confirmation. Votre carte reste intacte dans tous les cas.

11À la fin de l'ingest

Une fenêtre de bilan s'ouvre, accompagnée d'un son. Sa couleur et son titre vous disent tout de suite si vous pouvez vous fier aux copies.

Tout s'est bien passé

Le titre dépend du mode :

  • ALL FILES COPIED & VERIFIED : SECURE ou PRO. Les copies sont prouvées identiques.
  • ALL FILES COPIED & SIZE-CHECKED : SIZE CHECK.
  • ALL FILES COPIED : FAST. Rien n'a été vérifié.

En dessous : mode, nombre de fichiers, taille, durée de chaque phase et vitesse moyenne. Puis, pour chaque carte, son dossier sur chaque disque.

  • REVEAL ouvre le dossier dans le Finder ou l'Explorateur.
  • EJECT éjecte la carte (EJECT ALL pour un lot).

Quelque chose s'est mal passé

La fenêtre passe au rouge et dit clairement ce qui s'est produit, par exemple 2 FILES DID NOT SURVIVE THE COPY TO NAS_BACKUP (2 fichiers n'ont pas survécu à la copie vers NAS_BACKUP). Sous le titre : Do not format this card, ne formatez pas cette carte.

La liste en dessous regroupe les fichiers en échec par cause. Une copie défectueuse est mise de côté sous un nom finissant par .ingesto-failed : aucun fichier abîmé ne porte un nom valide dans votre dossier de livraison.

Re-copy 2 failed files recopie et revérifie ces fichiers, et seulement eux. La file affiche la progression comme d'habitude.

La règle

Tant que le bilan n'est pas vert et vérifié, gardez la carte. Si une recopie échoue encore sur le même disque, soupçonnez le disque ou son câble. Si ingesto indique que la carte ne rend pas deux fois les mêmes données, c'est la carte elle-même qui lâche : mettez-la de côté.

Deux remarques possibles sur un bilan vert

  • En bleu, You can double-check this later. Le contrôle a eu lieu juste après la copie, et une partie a pu être servie par la mémoire de l'ordinateur plutôt que par le disque. L'ingest est vérifié ; pour plus de tranquillité, un autre jour, rebranchez le disque et vérifiez le dossier (chapitre 13).
  • En orange, The extra card check did not really run (PRO avec double lecture de la source). Vos rushes sont bons et vérifiés, mais la seconde lecture de la carte est venue de la mémoire de l'ordinateur : elle n'a pas testé la santé de la carte. Quand c'est possible, un bouton propose de refaire ce contrôle de la carte pour de bon.

12Historique et rapports

L'historique d'ingest

Dès qu'une destination est chargée, la colonne centrale liste toutes les cartes déjà copiées dessus : numéro, nom de carte, dossier, nombre de disques, et un badge d'état VERIFIED ou FAILED.

  • Cliquez sur une ligne pour voir le détail : date, nombre de fichiers, taille, durée, vitesse, mode, durée de chaque phase, toutes les destinations, opérateur, caméra, profil et notes.
  • L'icône dossier en bout de ligne montre ce dossier sur le disque.
  • L'historique est lu dans les rapports écrits sur les disques. Il survit à un redémarrage, et un disque venu d'un autre ordinateur arrive avec son propre historique.
  • La gomme dans l'en-tête vide la liste dans ingesto seulement. Les rapports sur les disques ne sont jamais touchés, et Show it again fait réapparaître les lignes.

Le rapport d'ingest

Après chaque ingest, ingesto met à jour un rapport à la racine de chaque destination. Open the report, sous l'historique, l'ouvre dans votre navigateur.

  • Une ligne par carte : numéro, date, carte, opérateur, caméra, mode, fichiers, taille, résultat, durée de chaque phase, notes.
  • Le bouton Export PDF le transforme en PDF à envoyer à la production ou à la post-production.
  • Des versions CSV (tableur) et JSON (pour des scripts) peuvent être ajoutées dans les réglages.

13Vérifier un dossier plus tard

L'icône livre en haut à droite revérifie un dossier déjà copié, sans rien recopier.

  1. Cliquez sur l'icône livre.
  2. Choisissez le dossier de la carte sur le disque.
  3. ingesto lit sa liste de checksums ou son manifeste MHL, relit chaque fichier et compare.

Le résultat indique combien de fichiers ont été contrôlés, sont conformes, corrompus ou manquants. ALL FILES VERIFIED signifie que le dossier est toujours identique à ce qui a été copié.

Quand s'en servir

Avant de confier un disque à la post-production, après un long transport, ou des mois plus tard avant l'archivage. Le dossier doit contenir une liste de checksums ou un manifeste : laissez Write Checksum activé dans les réglages (il l'est par défaut).

14Réglages

L'icône engrenage en haut à droite ouvre les réglages, Settings. Chaque section a son interrupteur. Done ferme la fenêtre ; tout est enregistré immédiatement.

Card Tracking (désactivé par défaut)

Écrit un petit fichier, .ingesto.json, sur la carte. Quand la même carte revient, ingesto sait si elle a été formatée depuis son dernier ingest. C'est la seule option qui écrive sur une carte, et c'est pourquoi elle demande confirmation quand vous l'activez.

Si une carte revient sans avoir été formatée, ingesto indique combien de fichiers ont déjà été copiés et combien sont nouveaux :

  • COPY NEW FILES : seulement ce qui a été tourné depuis. Un fichier n'est sauté que si chaque destination en détient déjà une copie vérifiée.
  • COPY FULL CARD : tout, à nouveau.
  • CANCEL : rien.

Utile quand une carte repart dans la caméra entre deux ingests.

Write Checksum (activé par défaut)

Écrit, à côté des rushes, des fichiers qui permettent à n'importe qui de recontrôler la copie plus tard (SECURE et PRO seulement) :

  • Checksum list : une liste .xxh / .md5, lisible par ingesto et TeraCopy.
  • MHL manifest : le format classique de Silverstack, YoYotta, OffShoot (PRO avec MD5 ou xxHash64).
  • ASC MHL : le standard plus récent de la profession, dans un dossier ascmhl.

Activez ce que demande votre post-production. Si personne ne demande rien, la liste de checksums seule suffit.

Ingest Report (activé par défaut)

Formats : HTML pour lire et imprimer, CSV pour un tableur, JSON pour des scripts. Full report liste chaque fichier de chaque carte ; désactivé, chaque carte tient en une ligne. VIEW ouvre le rapport actuel.

File Filter (désactivé à chaque lancement)

Ne copie que les types de fichiers choisis : vidéo, audio, images, et autres fichiers (fichiers annexes comme XML, THM…), type par type.

Copy empty folders conserve les dossiers vides de la carte.

Reorganize files on destination range les fichiers copiés dans /VIDEO, /AUDIO, /PICTURES. Les autres fichiers ne sont alors jamais copiés.

À manier avec prudence

Un ingest filtré n'est pas une copie complète de la carte. C'est pour cela que le filtre se désactive à chaque lancement : il faut le rallumer volontairement à chaque fois. Votre choix de formats, lui, est conservé.

Beaucoup de caméras ont besoin de leurs fichiers annexes (XML, dossiers de métadonnées) pour être lues correctement en montage. Dans le doute, laissez le filtre désactivé.

Phone Notifications (ntfy) (désactivé par défaut)

Recevez une notification sur votre téléphone après chaque carte : carte, opérateur, caméra, nombre de fichiers, taille, mode, résultat par disque, durée de chaque phase, notes. Une carte en échec est envoyée en priorité haute.

  1. Installez l'application gratuite ntfy (iPhone, Android) : scannez le QR code.
  2. Dans ingesto, saisissez un Topic : un nom long et difficile à deviner.
  3. Dans l'application, abonnez-vous à ce même topic.
  4. Cliquez sur Send test notification et regardez votre téléphone.

Laissez le Server sur https://ntfy.sh sauf si vous avez votre propre serveur.

Confidentialité

Sur le serveur public, le nom du topic est la seule protection de vos notifications. Quiconque le connaît peut les lire. Choisissez quelque chose comme ingesto-studio-7x2k, pas ingesto.

Post-Ingest Command et Card Handoff (désactivés par défaut)

Deux options pour les utilisateurs techniques qui automatisent leur workflow avec des scripts. Post-Ingest Command lance une commande après chaque ingest. Card Handoff confie chaque carte à un script de votre choix, avec un document qui décrit ce qui a été copié et vérifié ; Dry run permet de le tester. Les deux exécutent exactement ce que vous tapez. Si vous ne savez pas quoi y mettre, laissez-les désactivées.

Settings File

Pour configurer plusieurs postes à l'identique. Export settings… enregistre un fichier ; Import settings… l'applique sur un autre ordinateur. Les interrupteurs choisissent ce qui est inclus : structure actuelle, modèles, mode de copie, Card Tracking, checksums, rapport, filtre de fichiers.

Ce qui n'est pas un réglage

Il n'y a pas de choix de langue : l'interface est en anglais. Les sons et le maintien en éveil de l'ordinateur sont automatiques. Le nombre de chiffres du compteur se règle depuis son propre ⓘ (chapitre 8), le code du kiosque depuis le bouton KIOSK (chapitre 15).

15Mode kiosque

Une vue simplifiée, verrouillée et plein écran, pour un poste partagé par toute une équipe : l'opérateur arrive, insère sa carte, tape son nom, lance. Personne ne peut modifier les réglages.

Préparer le poste

  1. Dans la fenêtre normale, chargez les destinations, choisissez le mode de copie et la structure de dossier. Le mode kiosque les utilise tels quels.
  2. Cliquez sur KIOSK en haut à droite.
  3. Choisissez un code à 4 chiffres, puis tapez-le à nouveau pour confirmer.

Pour la personne qui fait l'ingest

  1. Insérez la carte, ou cliquez sur Browse a card….
  2. Tapez votre nom dans Operator (obligatoire). Caméra, profil et notes sont facultatifs ; la caméra est souvent remplie automatiquement.
  3. Cliquez sur START INGEST et suivez le grand anneau de progression.
  4. Lisez le résultat, puis cliquez sur Next card.

L'écran de résultat parle clairement :

  • Verified : « You can remove your card » (vous pouvez retirer votre carte). La carte est éjectée automatiquement.
  • Après FAST ou SIZE CHECK : « Remove your card. Do not erase it » (retirez votre carte, ne l'effacez pas).
  • En cas de problème : « Do not erase it. Call the person in charge » (ne l'effacez pas, appelez le responsable).

Si aucune destination n'a été choisie, l'écran affiche Not set up yet et demande la personne qui a préparé le poste.

Quitter le mode kiosque

Cliquez sur STANDARD en haut à droite et saisissez le code. Après cinq erreurs, le pavé se bloque 30 secondes.

Code oublié

Quittez et relancez ingesto : il démarre toujours dans la fenêtre normale. Le code n'est jamais enregistré ; il ne vaut que pour la session.

16Gérer les volumes

La zone MOUNTED VOLUMES montre toutes les cartes, tous les disques et partages branchés, avec une icône par type (carte, disque, réseau, disque système) et l'espace libre.

CommandeUsage
HIDE SYSTEMMasque le disque interne de l'ordinateur.
HIDE NETWORKMasque les partages réseau.
Clic droit → Hide VolumeMasque un volume précis. L'icône œil de l'en-tête réaffiche les volumes masqués.
Clic droit → EjectÉjecte une carte ou un disque sans quitter ingesto. Non proposé pour le disque système ni les partages réseau, et refusé pendant un ingest. Si le volume était chargé, il est retiré une fois l'éjection réussie.
Flèche circulaireRafraîchit la liste.

Sous Windows, la lettre de lecteur d'une carte est affichée dans la liste, par exemple LUMIX (D:), pour distinguer deux cartes identiques dans deux lecteurs. Le nom du dossier et le rapport utilisent le nom seul, LUMIX.

17Bonnes pratiques en tournage

ingesto se charge des contrôles. Ces habitudes rendent le reste de la chaîne tout aussi sûr.

Avant le tournage

  • Installez ingesto et faites un ingest d'essai avec une vraie carte.
  • Préparez la structure de dossier et enregistrez-la comme modèle.
  • Configurez ntfy et envoyez une notification de test.
  • Préparez au moins deux disques de destination, formatés et avec assez de place pour la journée.

Pour chaque carte

  • Mode SECURE (ou PRO si demandé).
  • Vérifiez le nom du dossier en vert sous chaque destination.
  • Renseignez l'opérateur, la caméra et les notes.
  • Attendez le bilan vert : ALL FILES COPIED & VERIFIED.
  • Seulement alors, rendez la carte à la caméra pour formatage.

En fin de journée

  • Regardez l'historique : aucune ligne rouge, aucun trou dans la numérotation.
  • Exportez le rapport en PDF pour la production si besoin.
  • Gardez les deux copies dans deux endroits différents.

18Dépannage

macOS dit qu'ingesto ne peut pas être ouvert, ou que le développeur ne peut pas être vérifié

Les versions à partir de la 2.5.5 sont signées et ne devraient pas afficher ce message. Si vous le voyez, vous avez une version plus ancienne ou une copie compilée vous-même : clic droit sur l'application dans Applications → Ouvrir → Ouvrir à nouveau. Une seule fois suffit.

Ma carte ou mon disque n'apparaît pas

Cliquez sur la flèche de rafraîchissement. Vérifiez qu'il apparaît dans le Finder ou l'Explorateur. Vérifiez que HIDE SYSTEM / HIDE NETWORK ne le masquent pas, et cliquez sur l'icône œil pour afficher les volumes masqués.

L'ingest refuse de démarrer

Lisez la fenêtre : elle nomme le problème et dit quoi faire. Rien n'a été copié. Les causes les plus courantes sont un disque débranché, deux cartes portant le même nom sans compteur dans la structure, ou un numéro de compteur déjà utilisé.

SECURE ou PRO est lent

C'est normal : chaque fichier est relu sur chaque disque, directement sur le support. Sur un partage réseau, la vérification peut durer aussi longtemps que la copie. C'est le prix d'un vrai contrôle.

Des fichiers ont échoué

Ne formatez pas la carte. Cliquez sur Re-copy. Si l'échec se reproduit sur le même disque, changez de câble ou de disque. Si ingesto indique que la carte rend des données différentes à chaque lecture, la carte lâche : mettez-la de côté.

Le compteur ne donne pas le numéro attendu

En mode Auto, il suit ce qu'il trouve sur les destinations. Regardez last: sous le compteur. Pour imposer un numéro, tapez-le ; cliquez sur Auto pour revenir.

J'ai masqué l'historique par erreur

Cliquez sur Show it again dans la zone historique. Les rapports sur les disques n'ont jamais été touchés.

La notification n'arrive pas

Vérifiez que le topic est exactement le même dans ingesto et dans l'application ntfy, et utilisez Send test notification. L'ordinateur doit être connecté à Internet.
