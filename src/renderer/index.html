Comparison
rename instead of copying again
A renamed or moved file is recognized by its file id and simply renamed on the other side — a 100 GB folder rename takes a second instead of a re-copy. Needs one previous run of this pair (the ids come from the sync database), works on local disks and mounted shares, not over SFTP.
Deletion
Most NAS shares and every SFTP server have no trash. syncto checks before it starts and refuses rather than deleting quietly: pick permanent deletion for those destinations, or turn on the switch below to let it fall back on its own wherever there is no bin.
After the synchronization
Only on a clean run: any error, a cancellation, or a lost folder lock leaves the machine alone so you can read what happened. A 30-second countdown with a Cancel button always comes first.
There is no hibernate entry on purpose — macOS has no such command, and on Windows it only works when hibernation is enabled, which it usually is not.
Phone notifications (ntfy)
Scan to install the ntfy app
Point your phone camera at the code — it opens ntfy.sh, where the free app is available for iPhone and Android. Subscribe it to the topic above, and the phone rings when a run ends.

The topic is the password. Anyone who knows it can read your notifications on the public server, so make it long and unguessable.
Copying
syncto-checksums.txt at the root of each target, checkable months later
one machine at a time per folder
A .syncto.lock file at the root of each synchronized folder, refreshed every 5 seconds while the run lasts. Another machine starting on the same folders waits and tells you who is running; a lock left behind by a crash is taken over after 12 seconds. Works over any network share — turn it off only if your storage forbids the extra file.

Filter — this job only
These patterns belong to the current job and travel with its .syncto file. Right-clicking any row in the grid or the overview adds patterns here too.
One pattern per line (or separated by |). * is any run of characters inside one name, ? is exactly one. End with / to mean folders only, with : to mean files only.
No / in the pattern → it matches the item's name, at any depth: *.tmp · thumbs.db · Proxies/
Starts with / → it matches one exact path from the folder above: /Rushes/A001/ · /notes.txt
